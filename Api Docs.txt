## 1. Feature & Screen Mapping

### Public Routes (No Authentication Required)
- `/` - Landing page (marketing)
- `/login` - User login
- `/register` - Company registration
- `/forgot-password` - Password recovery

### Manager Routes (`/dashboard`, `/employees`, `/annual-plan`, etc.)
- `/dashboard` - Manager dashboard with KPIs and monthly performance tracking
- `/employees` - Employee list with search and filters
- `/employees/add` - Add new employee form
- `/employees/[id]` - Employee details page
- `/annual-plan` - Annual plan creation and management (AI-generated)
- `/weekly-costs` - Weekly task distribution and management
- `/weekly-reports` - View all employee weekly reports
- `/weekly-reports/[id]` - Individual weekly report details
- `/weekly-report` - Manager's weekly report view
- `/daily-reports` - Daily reports list
- `/daily-reports/[id]` - Individual daily report details
- `/suggestions` - Employee suggestions list with filters
- `/suggestions/[id]` - Suggestion details and review
- `/important-notes` - View important notes from employees
- `/monthly-reports` - Monthly performance analysis and AI-generated reports
- `/settings` - Manager settings (company profile, password, subscription)

### Employee Routes (`/employee/*`)
- `/employee/dashboard` - Employee dashboard
- `/employee/weekly-tasks` - View assigned weekly tasks
- `/employee/weekly-report` - Submit weekly report
- `/employee/daily-report` - Submit daily report
- `/employee/suggestions` - View own suggestions
- `/employee/suggestions/create` - Create new suggestion
- `/employee/important-notes` - Manage important notes (CRUD)
- `/employee/notes` - Personal notes
- `/employee/settings` - Employee settings

### Super Admin Routes (`/super-admin/*`)
- `/super-admin/dashboard` - Super admin dashboard with company stats
- `/super-admin/companies` - Companies list
- `/super-admin/companies/[id]` - Company details (password change, activate/deactivate)
- `/super-admin/subscriptions` - Subscription plans management
- `/super-admin/settings` - Super admin settings

## 3. Request Specifications

### Authentication Headers
All authenticated requests require:
```
Authorization: Bearer <token>
```
or
```
Cookie: rafeed_auth=<user_data>
```

### Common Query Parameters

#### Pagination
- `page`: number (default: 1)
- `limit`: number (default: 10, max: 100)

#### Filtering
- `search`: string (searches across relevant fields)
- `status`: string (varies by endpoint)
- `date`: string (ISO date or relative: 'today', 'week', 'month')
- `employeeId`: string
- `month`: number (1-12)
- `year`: number
- `week`: number (1-5)

#### Sorting
- `sortBy`: string (field name)
- `sortOrder`: "asc" | "desc" (default: "desc")

### Validation Rules

#### Email
- Valid email format
- Required for registration/login

#### Phone
- Format: `+966XXXXXXXXX` or similar
- Required for registration

#### Password
- Minimum 6 characters
- Required for registration/password change

#### Required Fields
- All fields marked as `required` in forms must be provided
- IDs in path parameters must be valid UUIDs or alphanumeric strings

## 6. Authentication & Authorization

### Authentication Mechanism
- **Method:** JWT tokens stored in cookies (`rafeed_auth`)
- **Token Format:** JSON Web Token (JWT)
- **Storage:** HTTP-only cookies (recommended) or localStorage
- **Expiration:** 24 hours (86400 seconds)

### Login Flow
1. User submits email/phone + password
2. Backend validates credentials
3. Backend generates JWT token
4. Token stored in cookie + returned in response
5. Frontend stores user data in localStorage (for client-side access)
6. All subsequent requests include token in Authorization header or cookie

### Protected Routes

#### Manager Routes (Role: `manager`)
- `/dashboard`
- `/annual-plan`
- `/employees`
- `/weekly-costs`
- `/weekly-reports`
- `/suggestions`
- `/important-notes`
- `/monthly-reports`
- `/settings`

#### Employee Routes (Role: `employee`)
- `/employee/*` (all routes under `/employee`)

#### Super Admin Routes (Role: `super-admin`)
- `/super-admin/*` (all routes under `/super-admin`)
- Super admin can access all routes

### Authorization Rules

#### Manager
- Can only access data from their own company
- Can manage employees in their company
- Can view all employee reports/suggestions in their company
- Cannot access other companies' data

#### Employee
- Can only access their own data
- Can view their own tasks, reports, suggestions
- Can create reports, suggestions, important notes
- Cannot access other employees' data
- Cannot access manager-only features

#### Super Admin
- Can access all companies and their data
- Can change company passwords
- Can activate/deactivate companies
- Can view all subscriptions
- Full system access

## Additional Notes

### Date Format
- All dates should be in **Gregorian (Miladi)** calendar
- ISO 8601 format: `YYYY-MM-DDTHH:mm:ssZ`
- Frontend displays dates using: `toLocaleDateString('en-US', { calendar: 'gregory' })`

### Language Support
- Primary language: Arabic (RTL)
- Secondary language: English (LTR)
- All API responses should support both languages or use language codes

### Currency
- Default currency: USD
- Format: `$50` or `50 USD`

### Subscription Plans
- Only two plans: **Starter (فضي)** and **Pro (ذهبي)**
- No Enterprise plan

### Important Implementation Notes
1. **Employee Registration**: Managers add employees and generate passwords for them
2. **Annual Plans**: AI-generated from a single goal, broken down into monthly/weekly goals
3. **Monthly Reports**: AI-generated analysis of employee performance
4. **Important Notes**: Employees can add notes visible to managers
5. **Super Admin**: Manages companies, not individual managers
